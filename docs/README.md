# 文档索引

> 本目录按「用途」分层，**一层只放一类文档**，新增文档前先确认属于哪一层。
> 全部相对链接由 `node scripts/check-doc-links.mjs` 校验，避免重组后路径漂移。

## 目录结构

| 目录 | 放什么 | 不放什么 |
|---|---|---|
| `01-需求/` | 需求基线、需求实现对照 | 实现细节 |
| `02-设计/` | 架构与技术说明、Agent 能力矩阵 | 页面规范 |
| `03-迭代/` | 首发前的开发过程记录：每轮改了什么、为什么、怎么验证 | 面向用户的变更说明（那在 CHANGELOG） |
| `04-规范/` | 界面开发规范、Git 分支与发布规范 | 实现说明 |
| `05-手册/` | 面向最终用户的手册 | 开发者文档 |

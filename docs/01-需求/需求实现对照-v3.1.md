## 0. 本轮已完成的优化（本次改动）

### 0.1 导航性能优化（核心）
**问题根因**：左侧导航 `Nav` 被写在**每一个页面**里（`app/*/page.tsx` 各自 `<Nav>` 包裹），而不是放在 `layout` 中。于是每次点击菜单跳转：
1. 整棵导航（含 200 节点侧栏）**卸载后重建**；
2. `Nav` 内部 `useEffect` 每次挂载都重新 `fetch('/api/auth/me')`，且立即把 `me` 置空 → **全屏「加载中…」白闪**，拿到响应后再重绘侧栏；
3. 每个页面自身又是客户端组件，在 `useEffect` 里二次拉数据，内容区先空后现。

这三件事叠加，就是「点菜单很慢、每次都在闪」的直接原因。

**修复**：
| 改动 | 文件 |
|---|---|
| 导航提升到根 layout，跨路由**持久化不重挂载** | `app/layout.tsx`、`components/AppShell.tsx`（新增） |
| 会话在**服务端一次性读取**并注入，彻底移除每个页面的 `/api/auth/me` 请求 | `app/layout.tsx`（`getSession()`） |
| `lib/auth` 的 DB 依赖改为**延迟导入**，让 layout 读会话时不初始化数据库 | `lib/auth.ts` |
| 新增**会话上下文** `useMe()`，页面零请求获取当前用户 | `components/SessionContext.tsx`（新增） |
| 边缘中间件做未登录**快速重定向**，消除客户端闪烁 | `middleware.ts`（新增） |
| 移除全部页面的 `<Nav>` 包裹与 `import Nav` | `app/{chat,docs,ppt,knowledge,files,projects,memory,skills,connectors,schedules,settings,admin}/page.tsx` |
| 修复 connectors 页 `localStorage` 读取角色的 Hack（含 SSR 水合不一致隐患） | `app/connectors/page.tsx` |
| 登录后会话自愈（服务端首屏为空时客户端兜底一次） | `components/AppShell.tsx` |

**效果**：点击菜单只替换内容区，侧栏与用户信息常驻；不再有整页白闪，不再每次导航请求 `/api/auth/me`。`middleware` 让未登录跳转在边缘完成。
